GitHub .bbmodel Viewer

Search public GitHub repositories for Blockbench models and preview them without downloading anything.

Settings

No token

Create a token at github.com/settings/tokens — no scopes are needed for public repositories. It is kept in this browser's localStorage and forwarded to api.github.com by the local dev server.

Find a model

A bare term gets extension:bbmodel appended. You can also paste a search?q=…, blob, or raw.githubusercontent.com URL to load a file directly.
